<Seccion id="primer-contacto" etiqueta="Práctica" titulo={<>Primer contacto con la <Clave>consola</Clave></>}>

Pulsa **▶ Ejecutar** en cada bloque y observa qué responde MySQL en la consola de abajo. También puedes escribir o pegar el código directamente en la consola. Por ahora solo observa: la sintaxis la explicamos en los próximos temas.

```sql
CREATE TABLE clientes (
  id_cliente INT PRIMARY KEY,
  nombre VARCHAR(50),
  ciudad VARCHAR(40),
  telefono VARCHAR(15),
  fecha_registro DATE
);
INSERT INTO clientes VALUES
(1, 'Laura Gómez', 'Bogotá', '3001234567', '2026-01-15'),
(2, 'Andrés Ruiz', 'Medellín', '3109876543', '2026-02-03'),
(3, 'Camila Torres', 'Cali', '3205551234', '2026-02-20');
SELECT * FROM clientes;
```

<Nota tipo="error" titulo="Error provocado">
  Ahora intenta registrar otro cliente con el `id_cliente` 1. ¿Por qué crees que el SGBD lo rechaza?
</Nota>

```sql
INSERT INTO clientes VALUES (1, 'Pedro Díaz', 'Pasto', '3150000000', '2026-03-01');
```
